# Glossary (DRAFT, definisi = `[K]` sampai disahkan)

| Istilah | Definisi kerja | Komponen/rumus (ringkas) | Sumber/keputusan |
|---|---|---|---|
| IDIR | Rasio angsuran baru thd penghasilan bersih (TPP/konsumsi) | `angsuran_baru / penghasilan_bersih` | D-11 `[K]`, golden `[K]` |
| DSR/DBR total | Rasio total kewajiban thd penghasilan bersih | `(angsuran_baru + kewajiban_eksisting_SLIK/internal) / penghasilan_bersih` | D-03,D-11 `[K]`, T2 |
| RPC | Kapasitas bayar produktif | `surplus * margin` (komponen eksplisit) | D-xx `[K]`, X2/X3 |
| DSCR | Debt service coverage | `RPC / debt_service_periodik` (definisi grace konsisten) | D-xx `[K]` |
| EIR/IRR efektif | Rate arus kas bersih (numerik) | **tanpa faktor 1,81x/0,87x** | D-05,V4 `[K]` |
| PPKA | Agunan dapat diperhitungkan (kualitas aset) | per kategori/enkumbransi/umur penilaian `[K→H]` | D-07 `[K]` |
| LTV | Loan/exposure to value | `exposure / basis_LTV` (basis tunggal, anti double-haircut) | D-07 `[K]` |
| Balloon/grace | Pokok/beban akhir tenor | `kecukupan = sumber / kewajiban_akhir`; ambang `[K]` | X3, D-xx `[K]` |
| BMPK | Batas maksimum pemberian kredit | pihak terkait/satu/kelompok `[K]` | D-13 `[K]` |
| Kolektibilitas | Kualitas aset (1–5) `[K]` | kriteria POJK kualitas aset `[K→H]` | D-16 `[K]` |
